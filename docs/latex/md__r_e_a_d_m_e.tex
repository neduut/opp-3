Programa, skirta apdoroti studentų duomenis. Programos versijose analizuojamas bei tobulinamas programos našumas, efektyvumas bei paruošimas vartotojuj.

Yra sukurta programos dokumentacija -\/ {\ttfamily dokumentacija.\+pdf}.\hypertarget{md__r_e_a_d_m_e_autotoc_md1}{}\doxysection{\texorpdfstring{Naudojimo instrukcijos}{Naudojimo instrukcijos}}\label{md__r_e_a_d_m_e_autotoc_md1}
{\bfseries{Katalogai\+:}}
\begin{DoxyItemize}
\item {\ttfamily analysis} -\/ programos veikimo analizės rezultatai, naudojami tam tikrose programos versijose
\item {\ttfamily docs} -\/ doxygen failai
\item {\ttfamily files} -\/ programoje vykdymo metu naudojami .txt failai (įtrauktas į {\ttfamily .gitignore} ir atsiras tik paleidus programą)
\item {\ttfamily include} -\/ antraščių {\ttfamily .h} failai
\item {\ttfamily src} -\/ {\ttfamily .cpp} failai
\end{DoxyItemize}

{\bfseries{Kad paleisti programą, turite atlikti šiuos veiksmus\+:}}


\begin{DoxyEnumerate}
\item Įeikite į norimos versijos katalogą
\item Paleiskite {\ttfamily run.\+bat} failą

{\ttfamily run.\+bat} failas atliks šiuos veiksmus\+:
\begin{DoxyItemize}
\item Sukurs build katalogą
\item Paleis CMake, kad sugeneruotų {\ttfamily Makefile}
\item Sukompiliuos projektą naudodamas make komandą
\item Paleis sukompiliuotą programą terminale
\end{DoxyItemize}
\end{DoxyEnumerate}

{\bfseries{Reikalavimai}}


\begin{DoxyItemize}
\item Operacinė sistema\+: Windows 10 x64-\/bit arba naujesnė versija
\item Įdiegta CMake (3.\+25 arba naujesnė versija)
\item Kompiliatorius\+: g++ (su C++11 arba naujesne versija)
